# Fresta

Instaladores da [Fresta](https://github.com/Dirt2939/fresta-releases/releases), a ilha no topo da tela.
O código não fica aqui: este repositório guarda só as versões publicadas.

- `windows/latest.json` — a versão mais nova para Windows. O app lê este arquivo para saber se há atualização.
- `linux/latest.json` — o mesmo para Linux, quando houver uma versão publicada.

Cada versão é uma release com a tag `windows-vX.Y.Z` ou `linux-vX.Y.Z`. O instalador do Windows se chama sempre `Fresta-Setup.exe`, então
https://github.com/Dirt2939/fresta-releases/releases/latest/download/Fresta-Setup.exe baixa sempre o mais novo.
